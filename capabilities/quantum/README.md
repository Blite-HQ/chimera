# blite-cap-quantum

Quantum optimization via QAOA (Qiskit + Aer, seeded for reproducible runs).

Scope note: earlier drafts promised VQC/VQE tools; those were descoped (the
official C3 track is TFIM) and are NOT provided by this package. The optional
extras `vqe`/`vqc`/`dwave` remain declared for future work but have no
implementation behind them.
