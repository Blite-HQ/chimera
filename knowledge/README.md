# Knowledge Base

Shared operational knowledge versioned alongside the code.
Each subdirectory covers a research area or scenario.

**Rule:** Knowledge goes here, not in capability packages.
Capabilities are generic tools (ADR-029); knowledge is how to
use those tools for a specific problem.

| Directory    | Content                                                                   |
| ------------ | ------------------------------------------------------------------------- |
| `islanding/` | Grid partitioning: problem formulation, QUBO mapping, evaluation criteria |
| `quantum/`   | Quantum circuit patterns, QAOA tuning, backend notes                      |
| `trust/`     | Verification protocols, certificate templates                             |
| `execution/` | Agent prompts, reasoning traces, run artifacts                            |
