# Notes — Class 03

## Resumen

First "fun math" session, framed as building the classical foundations needed before introducing quantum systems the next day. Covers deterministic classical systems (alphabets, the 4 possible Boolean functions on one bit), scaling to n systems, probabilistic classical systems (probability vectors, stochastic matrices), a fully worked coin-flip protocol example, tensor products for combining independent systems, the key observation that correlation/non-decomposability is not uniquely quantum, and the CNOT gate worked out as a classical stochastic matrix.

## Conceptos clave

- **Motivation / course arc** [~00:00]: today's material formalizes classical systems mathematically so that tomorrow's session can introduce quantum systems as a generalization; logistics recap (Canvas assessment now live, Discord has the recording link).
- **Deterministic classical systems** [~00:00]: a system is described by an alphabet/set of labels for its possible states; the simplest case is a single bit with states {0,1}.
- **The 4 possible functions {0,1}→{0,1}** [~00:00–20:00]: constant-0, identity, negation (NOT), constant-1 — enumerated as the complete set of deterministic single-bit transformations.
- **Scaling to n systems** [~20:00]: a system built from n bits has 2^n possible states; the number of possible deterministic functions on that system grows super-exponentially, 2^(2^n), since a function is specified by an independent output choice for each of the 2^n inputs.
- **Probabilistic classical systems** [~20:00–40:00]: instead of a definite state, a system is described by a probability vector (entries ≥0, summing to 1) — a convex combination over the deterministic basis states.
- **Stochastic matrices** [~40:00]: the correct generalization of a deterministic transformation to the probabilistic setting; a matrix transforms one probability vector into another and must satisfy two properties: (1) every entry is ≥0, (2) every column sums to 1.
- **Worked coin-flip protocol example** [~40:00]: a 2×2 stochastic matrix is built for a protocol where tails deterministically turns into heads (column 1 = [0,1]) and heads gets flipped again with bias p/q (column 2 = [p,q]); applying the matrix to an input vector gives the output probabilities via ordinary matrix-vector multiplication (worked components pq and p²+pq shown explicitly).
- **Tensor products of vectors** [~40:00–60:00]: combining two independent probabilistic systems (each 2-dimensional) produces a 4-dimensional joint system via the tensor product, e.g. [p,q]⊗[r,s] = [pr, ps, qr, qs].
- **Non-decomposability / correlation is not uniquely quantum** [~60:00]: the instructor stresses, as a deliberate pedagogical point repeated multiple times, that not every 4-dimensional joint probability vector factors as a tensor product of two 2-dimensional ones — this signals correlation/dependence between the two subsystems, and this phenomenon already exists classically, i.e. it is *not* a uniquely quantum feature (a preemptive correction against the common misconception that "quantum = correlated, classical = independent").
- **Tensor products of transformations** [~60:00]: two 2×2 stochastic matrices combine via tensor product into a single 4×4 stochastic matrix acting on the joint system.
- **CNOT as a classical stochastic matrix** [~60:00–80:00]: CNOT is worked out explicitly as a 4×4 matrix with a top-left 2×2 identity block and a bottom-right 2×2 NOT block; like the correlated probability vectors above, this matrix cannot be decomposed as A⊗B, because CNOT creates a correlation between the control and target bit values — reinforcing that entangling-like correlation exists in purely classical stochastic systems too.
- **Closing thought experiment (optional, left open)** [~80:00]: how to simulate a fair coin flip using only a biased coin of unknown bias — posed as a discussion question, not resolved in the session.

## Fórmulas y definiciones

- **4 deterministic functions on {0,1}**: constant-0, identity, negation, constant-1. [~00:00–20:00]
- **State count for n bits**: 2^n possible states. [~20:00]
- **Function count for n bits**: 2^(2^n) possible deterministic functions. [~20:00]
- **Probability vector**: entries ≥0, sum to 1; represents a convex combination of deterministic basis states. [~20:00–40:00]
- **Stochastic matrix conditions**: (1) all entries ≥0; (2) every column sums to 1. [~40:00]
- **Worked stochastic matrix (coin-flip protocol)**: column 1 = [0,1] (tails→heads deterministically), column 2 = [p,q] (heads→flip again with bias p, q=1−p); output computed via matrix-vector multiplication, giving components including pq and p²+pq. [~40:00]
- **Tensor product of vectors**: [p,q]⊗[r,s] = [pr, ps, qr, qs] (2-dim ⊗ 2-dim → 4-dim). [~40:00–60:00]
- **Tensor product of matrices**: 2×2 ⊗ 2×2 → 4×4 stochastic matrix acting on the combined system. [~60:00]
- **CNOT (classical, stochastic-matrix form)**: 4×4 matrix, top-left 2×2 block = identity, bottom-right 2×2 block = NOT; not expressible as A⊗B. [~60:00–80:00]

## Glosario

- **Alphabet**: the set of labels describing a classical system's possible states. [~00:00]
- **Stochastic matrix**: a matrix with all entries ≥0 and each column summing to 1; the probabilistic generalization of a deterministic transformation. [~40:00]
- **Convex combination**: a weighted sum of states with non-negative weights summing to 1, used to describe a probability vector over basis states. [~20:00–40:00]
- **Tensor product**: operation combining two independent systems' vectors (or transformations) into a joint system of multiplied dimension. [~40:00–60:00]
- **Non-decomposable / correlated probability vector**: a joint probability vector that cannot be written as a tensor product of its marginal (independent) parts — signals dependence between subsystems. [~60:00]
- **CNOT**: controlled-NOT gate; here shown in its classical stochastic-matrix form (identity ⊕ NOT block), also non-decomposable. [~60:00–80:00]
