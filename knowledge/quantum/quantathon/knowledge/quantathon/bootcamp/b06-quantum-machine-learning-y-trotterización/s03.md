### Slide/Page 13

¿Que nos motiva a usar Quantum?
• Diferentes tipos de computación pueden ser más adecuados para 
distintos tipos de datos.
• Algunos datos provenientes de sistemas físicos pueden 
representarse de forma más natural usando estados cuánticos.
• En muchos casos, el proceso consiste en transformar los datos 
clásicos y llevarlos a un espacio de mayor dimensión.
• Los estados cuánticos permiten codificar información en 
espacios muy grandes, lo que puede ayudar a encontrar 
patrones difíciles de ver en la representación original.

• Los métodos de kernel son solo una de las muchas maneras en que podemos
mapear datos a dimensiones superiores.
• Los métodos de kernel se eligen de manera que los productos escalares
se calculen de forma eficiente en dimensiones superiores.

producto escalar en la dimensión inferior.

### Slide/Page 25

Uso Quantum Kernels
• Idea: podemos usar un circuito cuántico para calcular el producto escalar.
• El producto punto surge de forma natural en la computación cuántica.
• La probabilidad de medir un vector específico dado otro vector es exactamente el producto 
escalar (normalizado).
• Esto significa que solo necesitamos codificar los vectores como estados cuánticos.
• Esto nos deja varias formas diferentes de representar los datos.

### Slide/Page 26

Basis Encoding
• La forma más simple de codificación: los qubits se 
utilizan para almacenar bits directamente, sin pérdida 
de datos.
• Requiere muchos qubits.
• La lectura de los datos se realiza de forma eficiente.
• También se utiliza en otros algoritmos, como el 
algoritmo de Shor.
• La superposición se puede utilizar para codificar más 
de una característica de un punto de datos, de forma 
similar a la codificación de amplitud.

### Slide/Page 27

Amplitude Encoding
Los datos se codifican en las amplitudes de 
probabilidad de un
estado cuántico.
• Se puede almacenar una cantidad exponencial de 
datos en un estado cuántico de n qubits.
• La codificación precisa de un estado cuántico dado 
puede ser muy ineficiente.
• La codificación con pérdida ayuda a encontrar un 
estado cuántico cercano que se puede codificar de 
forma más eficiente.
• La lectura de los datos codificados requiere una 
cantidad exponencial de mediciones.

### Slide/Page 42

Cómo Elegir Un Encoding?
Depende de tres preguntas:
1. ¿Cuántas features tengo?
2. ¿Cuántos qubits puedo usar?
3. ¿Necesito capturar interacciones entre features?
Regla práctica:
●Si quiero algo simple: angle encoding.
●Si tengo pocos qubits: dense encoding.
●Si quiero un kernel más expresivo: ZZ feature map.
